# 💗 Loverlist —— 人物与影视作品管理系统

单机自用的**人物 + 影视作品(番号)收藏管理器**:SQLite 本地存储、Flask + waitress 中文 Web 界面,
内嵌便携版 Python 3.11.9,无需安装系统级 Python。

## 功能一览

- **人物**:增删改查、姓名/别名/假名模糊搜索、按事务所/性别筛选、按心动指数/姓名/身高/年龄/罩杯排序(支持升序/降序,空值恒排最后)、分页
  - 资料字段:姓名、**别名(可多个,用 `、/,/;` 分隔,详情页以标签列表展示)**、假名(日文)、性别(默认女)、出生年月(YYYY-MM)、身高、三围(B/W/H)、罩杯、备注
  - **心动指数**:无上限整数,仅人物列表/人物详情/作品详情三处可点 💗 +1(不刷页),其余页面纯展示
  - **收藏**(★ 心头好)与**事务所历史**(多段,`2016-2019: 甲事务所;2019-至今: 乙事务所`)
  - **头像**:正方形图片自动缩放为 512×512 保存;非正方形会弹出裁剪框(选区可拖动/缩放),本地存于 `data/avatars`,列表/详情/心动榜均有展示,支持移除
- **作品**:番号**分两段填写**(英文 + 数字均必填:英文自动转大写,数字仅保留数字字符、不足 3 位自动补零、超过原样保留,如 `LOV`+`7` → `LOV-007`)、标题、
  风格TAG(标签云精确筛选,超过 20 个自动折叠)、**文件名**(详情页一键复制)、备注
- **作品状态**:评审中 / 已收录 / 不予收录;新建作品默认**评审中**,存量导入空状态视为已收录;状态**只能在评审页更改**;「不予收录」只出现在 /works 列表(支持状态筛选),人物详情/仪表盘/标签云/统计均排除
- **评审页**:导航带待审角标;列出全部评审中作品,一键判「已收录 / 不予收录」;已判定区可「退回评审」
- **阵容关联**:作品页添加/移除出演人物(关系类型可自由输入,默认"出演");人物页反向列出 TA 的全部作品
- **心动向**:心动榜 Top 20、收藏列表、**今日心动**(每天按心动指数加权随机选一人,当日固定、次日重抽)
- **仪表盘**:人物/作品/TAG/总心动统计 + 今日心动 + 心动 Top5 + 最新作品
- **数据管理**:三份 CSV(persons/works/credits)导出下载(UTF-8-SIG,Excel 双击不乱码)、
  上传导入(**存在即更新**:人物按姓名、作品按番号、阵容按"人物+作品+关系";无法配对则跳过)、一键灌入演示数据
- 演示数据:8 位虚构人物(含三围/罩杯/事务所史)+ 10 部作品 + 29 条阵容

## 快速开始

```bat
:: 1. 首次使用:安装依赖(引导 pip 并安装 requirements.txt)
setup.bat

:: 2. 日常启动(自动开浏览器,访问 http://127.0.0.1:5000)
run.bat
```

也可以手动执行:

```
PYTHON\python.exe main.py            # 启动服务
PYTHON\python.exe main.py --demo     # 灌入演示数据后退出(仅空库生效)
PYTHON\python.exe main.py --port 8080 --no-browser
```

- 数据库文件:`data\loverlist.db`,首次运行自动建表;**想清空重来,删掉这个文件即可**
- 服务地址:`http://127.0.0.1:5000`(仅本机,无登录鉴权,请勿开放到公网)

## 测试

```
PYTHON\python.exe -m unittest discover tests
```

覆盖:建库与约束、人物/作品/阵容业务、列表筛选排序分页、今日心动确定性、
CSV 往返(导出→清空→导入还原)、Web 请求流。当前 **41 例全部通过**。

## CSV 格式

| 文件 | 列 |
|---|---|
| persons.csv | 姓名、别名、假名、性别、出生年月、身高、胸围、腰围、臀围、罩杯、心动指数、收藏、备注、事务所历史 |
| works.csv | 番号、标题、风格TAG、文件名、状态、备注 |
| credits.csv | 人物姓名、作品番号、关系类型、角色名 |

- 事务所历史单元格内多段用 `;` 分隔,段格式 `2018-至今: XX事务所`(结束年留 `至今` 表示现任)
- 风格TAG 在单元格内用 `,` 分隔
- **导入不覆盖心动指数与收藏**(它们由应用内点击产生)
- 日常备份建议:定期在「数据」页导出三份 CSV

## 目录结构

```
Loverlist/
├── main.py            # 入口:waitress 启动 / --demo
├── setup.bat          # 一键安装(引导 pip + 依赖)
├── run.bat            # 一键启动
├── requirements.txt   # 依赖钉版本(flask 3.1.3 / waitress 3.0.2)
├── loverlist/         # 应用包:__init__(工厂) db(建库) services(业务) csvio(导入导出) demo(演示数据) routes(视图)
├── templates/         # Jinja2 模板(全中文)
├── static/style.css   # 原生 CSS,无前端构建链
├── data/              # loverlist.db(不入库)
├── tests/             # unittest 标准库测试
└── PYTHON/            # 内嵌 Python 3.11.9(不入库,可从 python.org 重下 embeddable package 重建)
```

## 预留字段

作品的**文件名**、**状态**两列只做纯文本存储与页面展示,不加任何逻辑,
等你后续开发"文件名字符串生成"与"状态机"时直接接管。
